## 📖 Abstract

This repository contains the implementation and supporting material for the IEEE CONIT 2026 paper titled **"A Multi-Metric Evaluation of K-Means Clustering for Tuberculosis Detection in Healthcare Domain."**

The study evaluates the performance of the K-Means clustering algorithm using multiple clustering evaluation metrics to analyze tuberculosis healthcare data.
